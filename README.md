# 番茄钟

一款适合放在桌面上的 macOS 番茄钟小组件：无边框圆角窗口、深色番茄配色、始终置顶，专注时一眼就能看到倒计时。

## 功能

- 三种模式：工作 25 分钟 / 短休息 5 分钟 / 长休息 15 分钟
- 每完成 4 个番茄后自动进入长休息
- 可在设置里自定义各模式时长
- 开始、暂停、跳过、重置
- 本轮进度圆点 + 今日完成数（保存在本机）
- 窗口置顶开关（默认开启）
- 时段结束时发送 macOS 桌面通知
- 可选的轻柔完成提示音
- 快捷键：空格开始/暂停，`R` 重置，`S` 跳过
- 自定义红/黄按钮：关闭会退出应用，黄色最小化

## 环境要求

- macOS
- [Node.js](https://nodejs.org/)（建议 18 或更新，需带 `npm`）

## 安装与运行

在终端中执行：

```bash
cd /Users/zoe/Applications/pomodoro
npm install
npm start
```

首次 `npm install` 会下载 Electron，可能需要一点时间。之后只需 `npm start` 即可打开小组件。

## 使用提示

- 拖动顶部标题栏即可移动窗口
- 点击右上角图钉可开关置顶
- 点击齿轮可改时长、开关提示音
- 今日完成数按自然日重置；本轮 4 个圆点会在完成第 4 个番茄后清空并进入长休息
- 跳过不会增加今日完成数

数据保存在 Electron 用户目录下的 `pomodoro-store.json`（一般在 `~/Library/Application Support/番茄钟/`）。
